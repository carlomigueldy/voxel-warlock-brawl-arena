# Project Memory

- **2026-07-10 — Launch-polish push (13 commits, `feat/launch-polish`)** — Closed FEAT-V1-01-01, FEAT-V1-05-01/02/03. Key decisions: (1) Ring-out stays the kill path — HP now floors at 1 instead of hitting 0/`alive=false`, and a low-HP knockback amplifier makes near-dead players ring out faster instead of dying to raw damage; gated by `CFG.SPELL_DAMAGE_LETHAL` so the old lethal-HP behavior can be flagged back on. (2) Blender asset pipeline is authoritative at [`scripts/blender/README.md`](../scripts/blender/README.md) — prefers a venv with `bpy` 5.0.1 on Python 3.11, falls back to headless `blender --background` when the venv/bpy isn't available; used for both the spell-icon set and dungeon props. (3) Spell icons are pre-rendered PNGs (33, Blender-generated) with an SVG fallback if a PNG is missing/fails to load. (4) Dungeon decorations are renderer-only (no gameplay/collision effect) and seeded from the broadcast `layout.seed`, so every client renders the identical prop layout without a network sync. (5) Graphics quality tiers persist to `localStorage` under `vwba.quality` and apply live via `window.__applyQualityTier` (no reload needed). (6) The service worker is network-first for `index.html` specifically (so shell HTML doesn't go stale) — bump `SW_VERSION` on every deploy or clients keep an old cached shell. (7) Asset diet took total GLB payload from 454MB to 71MB via texture downscaling, not polycount/mesh decimation, plus pruning orphaned/dead assets from the pipeline. See [[live-domain-is-custom-not-vercel-subdomain]] for the related SEO/OG fix that landed in the same window.
